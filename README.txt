GVEX HTML Android starter prototype

Files:
- index.html: responsive colorful UI
- manifest.json: PWA metadata
- sw.js: basic offline cache

IMPORTANT:
This is a front-end prototype only. Registration and login are session-only, OTP is displayed locally, and no real payment or withdrawal happens. Do not use real personal details, passwords, wallet addresses, or funds.

To create an APK:
1. Host this folder on an HTTPS site (for example, a GitHub Pages site).
2. Open https://www.pwabuilder.com/ and enter the hosted HTTPS URL.
3. Follow its Android package workflow and review the generated project before building.
4. For more control, use Capacitor in a computer environment: https://capacitorjs.com/docs/android

A real production app needs secure backend authentication/database, server-side access policies, transaction verification, security review, and legal approval before any money-related feature is enabled. The five-level compensation and membership-payment model has not been legally validated. Do not enable real-money recruitment payouts without qualified legal advice.
